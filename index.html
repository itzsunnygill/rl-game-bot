RL Bot Setup

Get Your Environment
Ready to Train

Everything you need to go from zero to training CartPole and Pong agents — step by step, with one-click copy commands.

⚠️

Requires Python 3.10+ — Check your version first: python --version. If you're on an older version, download the latest from python.org before continuing.

Core Libraries

🤖 stable-baselines3 Core

Pre-built RL algorithms (PPO, DQN, A2C, SAC). Train agents in one line — the backbone of this project.

🏋️ gymnasium Core

OpenAI's environment toolkit. Provides CartPole, Pong, LunarLander, and 100+ training environments.

🔥 torch (PyTorch) Core

The deep learning engine powering all neural networks. Required by stable-baselines3 under the hood.

🔢 numpy Core

Fast numerical computing. Handles observations, rewards, and all array operations during training.

📊 matplotlib Extra

Plot reward curves and visualize training progress over episodes to understand how your agent improves.

🕹️ ale-py + ROMs Extra

Arcade Learning Environment for Atari games. Enables Pong, Breakout & classic Atari training.

🖼️ opencv-python Optional

Image preprocessing for pixel-based envs. Required when training directly from raw screen frames.

📈 tensorboard Optional

Real-time training dashboard. Visualize loss, entropy, and reward metrics live while your agent trains.

1

Upgrade pip

Always upgrade pip first to avoid dependency resolver issues.

bash 
pip install --upgrade pip
2

Install PyTorch

On Windows, use pytorch.org to get the exact command for your CUDA version. CPU-only fallback shown below.

bash 
pip install torch torchvision torchaudio
3

Install Gymnasium + Stable-Baselines3

The core RL stack — environments and pre-built algorithms.

bash 
pip install gymnasium stable-baselines3[extra]
4

Install Atari support (for Pong)

Install ale-py, then download the actual game ROMs legally via AutoROM.

bash 
pip install ale-py gymnasium[atari] autorom[accept-rom-license]
5

Run AutoROM to download game ROMs

This step is mandatory for Atari games. Skip it and Pong won't load.

bash 
AutoROM --accept-license
6

Install optional extras

Plotting, image preprocessing, and TensorBoard for training dashboards.

bash 
pip install matplotlib opencv-python tensorboard
Run the script below in your terminal. If CartPole prints "Setup works!", your environment is ready to go. 🎉

Quick Verification Checklist

  • ✓ Python 3.10 or higher installed
  • ✓ PyTorch imports without error
  • ✓ Gymnasium creates CartPole-v1
  • ✓ Stable-Baselines3 imports PPO
  • ! Atari ROMs installed (only needed for Pong)

Verification Script — Save as verify.py and run it

python 
# verify.py — Run this to confirm everything is installed

import sys

# 1. Check Python version
assert sys.version_info >= (3, 10), "Python 3.10+ required"
print(f"✅ Python {sys.version_info.major}.{sys.version_info.minor}")

# 2. Check PyTorch
import torch
print(f"✅ PyTorch {torch.__version__} | CUDA: {torch.cuda.is_available()}")

# 3. Check Gymnasium + CartPole
import gymnasium as gym
env = gym.make("CartPole-v1")
obs, _ = env.reset()
env.close()
print("✅ Gymnasium — CartPole-v1 loaded")

# 4. Check Stable-Baselines3
from stable_baselines3 import PPO
print("✅ Stable-Baselines3 — PPO imported")

# 5. Quick agent test
env = gym.make("CartPole-v1")
model = PPO("MlpPolicy", env, verbose=0)
model.learn(total_timesteps=1000)
env.close()
print("✅ PPO trained on CartPole for 1000 steps")

print("\n🎉 Setup works! You're ready to train RL agents.")

Run the script

bash 
python verify.py
🕹️

Testing Pong / Atari? After Steps 4 & 5 above, test with:
python -c "import gymnasium as gym; env = gym.make('ALE/Pong-v5'); print('Pong OK')"
